# Referências e originalidade

Este pacote organiza conhecimento operacional para produção de animação no Studio.

## Regra
Referências externas são usadas para estudar:
- estrutura;
- ritmo;
- enquadramento;
- movimento;
- composição geral.

Não copie:
- personagens;
- nomes;
- piadas;
- identidade visual;
- música;
- voz característica;
- logos;
- cenas específicas.

Se uma referência estiver próxima demais do projeto, transforme a inspiração em princípios abstratos e crie uma solução original.

## Material do Studio
Os três arquivos-base do Studio foram preservados nesta pasta. Os documentos de animação são complementares.
