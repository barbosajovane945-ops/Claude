# Sistema de cena

## Cenário
Cada cena deve comunicar onde o personagem está.

Inclua apenas elementos que ajudem:
- arquitetura;
- móveis;
- objetos de uso;
- iluminação;
- sinais visuais;
- profundidade.

Evite fundo vazio quando a cena precisa de contexto.

## Camadas
Organize, quando possível:
1. fundo;
2. elementos distantes;
3. objetos intermediários;
4. personagem;
5. elementos de primeiro plano;
6. UI/texto.

## Objetos
Todo objeto deve ter:
- posição física coerente;
- escala coerente;
- sombra ou contato quando necessário;
- perspectiva consistente.

## Câmera
Use:
- plano aberto para estabelecer;
- plano médio para ação;
- close para reação/detalhe;
- movimento de câmera somente quando acrescentar informação.

Não use zoom/pan aleatório como decoração.

## Texto
Legendas, balões e HUD devem:
- permanecer legíveis;
- não cobrir rosto;
- não esconder ação importante;
- respeitar margem segura vertical.
