# Templates de prompt para o Claude

## Criar personagem
Crie o personagem como um boneco articulado consistente com a bíblia da série. Preserve rosto, proporções, cabelo, roupa e acessórios aprovados. Separe as partes para permitir animação. Não invente mudanças de design.

## Criar cena
Construa a cena completa para vídeo vertical. Inclua fundo, objetos e iluminação coerentes com o local. Organize em camadas para permitir animação. Mantenha o personagem no design aprovado.

## Animar ação
Anime a ação descrita usando uma sequência legível: preparação, ação e acomodação quando necessário. Não mova elementos sem motivo. Preserve contato dos pés com o chão e das mãos com os objetos.

## Analisar referência
Separe a análise em:
1. estrutura;
2. timing;
3. enquadramento;
4. movimento;
5. identidade visual.

Use apenas os quatro primeiros como referência. Não copie identidade.

## Revisar frame sheet
Inspecione cada quadro procurando erros de corpo, objetos, roupa, texto, composição e continuidade. Liste correções concretas antes do render final.
