# Checklist de qualidade

Antes do render final, confirme:

## História
- [ ] O plano corresponde ao roteiro aprovado.
- [ ] A continuidade bate com a bíblia.
- [ ] O resultado do voto é o resultado real.
- [ ] Recursos e dinheiro fecham.

## Personagem
- [ ] Rosto aprovado.
- [ ] Corpo aprovado.
- [ ] Roupa correta.
- [ ] Sem membros duplicados.
- [ ] Sem objetos atravessando o corpo.
- [ ] Expressão corresponde à ação.

## Cenário
- [ ] Fundo completo.
- [ ] Objetos no lugar.
- [ ] Escala coerente.
- [ ] Sombras/contatos plausíveis.
- [ ] Nenhum objeto aparece ou desaparece sem motivo.

## Texto
- [ ] Legível.
- [ ] Dentro da área segura.
- [ ] Não cobre informação importante.

## Áudio
- [ ] Voz clara.
- [ ] SFX pontuais.
- [ ] Sem loop irritante.
- [ ] Mix final conforme regra do Studio.

## Continuidade
- [ ] Sementes visuais continuam.
- [ ] Estado atual foi atualizado.
- [ ] Voto foi registrado.
- [ ] Alterações importantes foram documentadas.
