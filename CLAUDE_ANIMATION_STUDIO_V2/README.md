# CLAUDE ANIMATION STUDIO V2

Esta é a versão unificada do Studio original + módulo de animação.

## O que foi preservado
Os arquivos originais `CLAUDE.md`, `COMECE-AQUI.md` e `entrevista-da-serie.md` foram mantidos como base do Studio.

## O que foi adicionado
- sistema de personagem articulado;
- linguagem de movimento;
- composição de cenas;
- biblioteca de movimentos;
- direção de áudio;
- revisão de qualidade;
- fluxo de render;
- templates de episódio e bíblia;
- templates de prompts;
- regras de referência e originalidade.

## Como usar
Abra esta pasta no Claude Code e diga:

> Leia o COMECE-AQUI.md e me guie.

Para criação de série:

> Leia entrevista-da-serie.md e me entreviste para criar a minha série.

Para produção de animação, o `CLAUDE.md` é a regra principal e os documentos `*_SYSTEM.md`, `MOTION_LIBRARY.md`, `AUDIO_EDITING.md`, `QA_CHECKLIST.md` e `RENDER_WORKFLOW.md` funcionam como manuais especializados.

## Princípio
Não é para "treinar" um modelo por fine-tuning. É um conjunto de contexto operacional e regras que o Claude deve consultar para produzir animações consistentes.
